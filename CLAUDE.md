# CLAUDE.md

This file just points to the canonical docs — read these two files before
doing anything else in this repo:

1. **`AGENTS.md`** — stack, project structure, coding standards, deploy steps.
2. **`docs/history.md`** — full chronological history of what was asked, what
   was decided, and why. Read this so you don't have to ask the user to
   re-explain context that already exists here.

When you make a non-trivial decision, finish a feature, or the user tells you
something worth remembering for next time, append it to `docs/history.md`
(don't rewrite earlier entries — it's a log, not a summary doc) and update
`AGENTS.md` if the project structure or conventions changed.
